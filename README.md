#  Currency Converter Web Application

##  Overview

This project is a responsive **Currency Converter Web Application** developed using **HTML, CSS, and JavaScript**. It allows users to convert currencies in real-time using a live exchange rate API. The application is designed with a clean and user-friendly interface suitable for travel and financial use cases.

---

##  Features

*  Real-time currency conversion using API
*  Instant auto-conversion on input
*  Currency swap functionality
*  Country flags for better UI experience
*  Conversion history tracking
*  Favorite currency option
*  Fully responsive design

---

##  Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript (ES6)** – Logic and API integration
* **Exchange Rate API** – Real-time currency data
* **Flags API (CDN)** – Display country flags

##  Setup Instructions

1. Clone the repository:

```
git clone https://github.com/your-username/currency-converter.git
```

2. Navigate to the project folder:

```
cd currency-converter
```

3. Open `index.html` in your browser
   OR run using Live Server in VS Code

---

##  API Configuration

* Get your free API key from:
  https://www.exchangerate-api.com/

* Replace in `script.js`:

